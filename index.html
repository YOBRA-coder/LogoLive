Can a live image really be a profile picture?
  • Yes, as an animated file. "Live" can't mean code running inside a profile photo, but a GIF or short looping video stays alive anywhere that accepts animated pictures.
  • Works: Telegram (video profile photo), Facebook (profile video), Discord (animated avatar, needs Nitro), plus statuses, stickers and wallpapers.
  • Static only: WhatsApp and Instagram. Use PNG still there.
  • Turn on Profile-safe layout so nothing gets cut off by the round crop.
